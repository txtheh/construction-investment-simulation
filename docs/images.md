## Рис. 3. Один игровой месяц

```mermaid
sequenceDiagram
    participant E as GameEngine
    participant P as Player
    participant V as RulesValidator
    participant A as RealtorAgency

    Note over E,P: Перед месяцем 1: начальная фаза (стартовые стройки)
    E->>E: 1. Списать затраты на строительство
    E->>E: 2. Зачислить выручку прошлого месяца
    E->>E: 3. Зачислить прибыль супермаркетов
    E->>P: 4. Запросить решение: стройки, продажи, реклама (PublicView)
    P-->>E: Decision
    E->>V: 5. Проверить решение
    V-->>E: Исправленное решение
    E->>E: 6. Снять расходы на рекламу
    E->>A: 7. Спрос и предложения
    A-->>E: Объёмы продаж
    E->>E: 8. Обновить объекты и капитал
```

## Рис. 4. Работа риэлторского агентства

```mermaid
flowchart TD
    S["Для каждого типа дома"] --> D["Узнать спрос"]
    D --> F["Убрать предложения с ценой выше предельной"]
    F --> SORT["Отсортировать по цене от низкой к высокой"]
    SORT --> L{"Остался спрос и есть предложения?"}
    L -- да --> T["Взять самую дешёвую цену"]
    T --> EQ["Если цены равны, делить спрос пропорционально объёму"]
    EQ --> SELL["Продать объём, уменьшить остаток спроса"]
    SELL --> L
    L -- нет --> AD["Применить бонус рекламы, не больше выставленного"]
    AD --> OUT["Вернуть продажи игроков"]
```
